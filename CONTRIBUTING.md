# Como colaborar

Este addon deve ser desenvolvido com testes simples e linguagem clara para uso
em oficina.

## Regras de projeto

- Toda funcao que gere G-code precisa ter teste.
- O G-code deve deixar a tocha desligada no fim.
- Cortes internos devem vir antes do contorno externo.
- A interface deve usar termos em portugues simples.
- Presets devem ser marcados como ponto de partida, nao como garantia de corte.

## Papel do Sandro

Sandro Ribeiro e colaborador do projeto e referencia de uso real:

- validar o fluxo dentro do FreeCAD;
- testar arquivos no Mach3 com tocha desligada primeiro;
- confirmar nomes e textos que fazem sentido para operador iniciante;
- informar parametros reais da mesa, plasma, espessura e material.
